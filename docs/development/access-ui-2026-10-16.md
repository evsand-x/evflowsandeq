## Kontrak dan pekerjaan
- Endpoint CRUD pengguna/peran dan PATCH permissions tersedia. Form lama drawer, matriks CRUD/tindakan terpisah.
- Tambah read detail/sesi/audit/anggota tereduksi dan daftar paginated berizin; aktif/nonaktif pada create role/user; status role revoke sesi; force revoke perusahaan dengan audit.
- Pertahankan gate ADMIN_SYSTEM dan permission tiap aksi di backend. Tidak mengarang permission data sensitif. Scope yang backend belum mampu menyelesaikan ID/semantiknya ditampilkan tersimpan/read-only, bukan kontrol yang seolah bekerja.
- Tambah halaman penuh serta matriks seluruh tindakan dengan highlight perubahan dan tinjauan sebelum apply. Simpan state tanpa perubahan izin nyata saat QA UI.
- Uji read company boundary, redaksi sesi/audit, schema status, permission matrix mapping; browser route nyata, typecheck/build/lint/validator.

## Hasil implementasi dan validasi
- Daftar, form buat/edit, detail Pengguna dan Peran sudah memakai route operasional; matriks gabungan memiliki pemisah modul, nama tindakan, highlight draf, dialog tinjau, discard dan perlindungan navigasi draf. Tabel pengguna membatasi badge tampak menjadi dua dengan tautan jumlah peran tambahan.
- Data assignment/created/sesi berasal dari backend, proyeksi snake_case diverifikasi pada sesi nyata. Pencarian tanpa hasil, pengaturan kolom, form penuh, tab anggota/riwayat/cakupan serta tinjau/discard izin diuji di browser. Tidak menerapkan perubahan hak akun nyata dalam QA.
- Desktop aktual 1600×1000 dibandingkan dengan referensi. Bukti: tmp/pdfs/access-redesign/users-final-review.png, user-detail-review.png, permission-review-review.png, user-form.png. Pengujian sempit dilakukan dengan mengembalikan viewport panel standar.
- Stack: Next/React/TypeScript, komponen bersama dan token CSS/Tailwind digunakan; Query untuk data server dengan kunci user/company/access; TanStack Table untuk tabel aktual; Sonner untuk hasil mutasi. Tidak ada dependensi native/mobile untuk scope ini.
- Typecheck Office, build contracts/backend, lint file yang berubah, 10 tes (persistensi/status/assignment/audit/session/company boundary/concurrency, gate nonadministrator, union izin) lulus. Validator repository lulus. Tidak ada migrasi database.
- Dokumen API, Design, Setting disinkronkan. Kebijakan ADMIN_SYSTEM terbaru 16 Oktober tetap dipertahankan; company isolation dan invariant backend tetap berlaku.
- Batas: scope selain perusahaan belum dapat diedit melalui resolver khusus; empat kategori sensitif belum memiliki permission terpisah. Keduanya ditandai baca saja/tidak tersedia. Riwayat dan sesi dibatasi 100 terbaru; metadata lama dapat tidak tersedia. Pagination daftar benar namun filtering masih in-memory pada kumpulan perusahaan, belum optimasi SQL untuk skala besar. Pemeriksaan visual mutasi destructive dan perubahan akses akun nyata sengaja tidak dilakukan; persistence diuji pada fixture terisolasi development.

## Matriks berjenjang — 16 Oktober 2026
Permintaan lanjutan: ubah baris matriks menjadi expand/collapse mengikuti sidebar. Gunakan pemetaan navigasi yang sudah tersedia, bentuk parent modul/kelompok/submenu, hanya satu cabang sejajar terbuka, dan pertahankan draf izin ketika cabang ditutup. Pencarian/filter membuka leluhur hasil agar izin tetap dapat ditemukan. Parent yang punya permission tetap menyimpan kontrol aslinya; parent struktural tidak memberi izin gabungan. Tidak mengubah API, grant atau otorisasi. Kriteria: keyboard Enter/Space, aria-expanded, accordion bertingkat, hasil pencarian terlihat, izin tidak hilang/duplikat.

Validasi matriks berjenjang: Office typecheck dan lint lulus; 5 tes pemetaan/accordion/filter lulus, termasuk parent yang memiliki permission sendiri dan penolakan duplikasi grant. Validator repository lulus. Pemeriksaan browser belum selesai: sesi localhost berakhir dan halaman login tampil; pengguna telah diminta login kembali. Tidak ada perubahan izin nyata, API, atau database pada tahap ini.
